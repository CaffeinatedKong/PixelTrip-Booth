# Feature: SETUP — Gather the party

Stage 1 of the six-stage adventure. This is where the party comes together before
the quest begins.

## What this stage does

- Create or join a trip and invite members into the shared party room.
- Build an 8-bit character (avatar, outfit, accessories) that represents each
  member's travel identity.
- Collect travel preferences: availability dates, budget, travel style,
  destination interests, and activity preferences.

This forms the party and gathers the preferences the AI NPC reasons over in the
later stages.
